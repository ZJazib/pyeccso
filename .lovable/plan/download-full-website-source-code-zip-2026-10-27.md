# Download: full website source code ZIP

## What you get
One ZIP file in Files containing the entire website source code: all pages, components, translations, admin panel, server code, database migrations, PHP bridge, scripts, images and configuration.

## What is left out
- Installed dependency folders (re-created with `bun install` / `npm install`)
- Build output folders (re-created by building)
- Git history and internal tool metadata
- The `.env` file with live keys (a `.env.example` with the variable names only is included instead)

## Steps
1. Copy the needed source into a clean staging folder.
2. List every staged file (including hidden ones) and check nothing important is missing or anything private is included.
3. Create `pyecso-source-code.zip`, inspect its contents, then save it to Files.
4. Share the download in chat.

No changes to the website itself.
